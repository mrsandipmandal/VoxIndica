The local studio server did not start

The desktop shell could not reach the bundled VoxIndica server within 20 seconds, so it stopped instead of showing a fake or empty workspace.

  1. Quit VoxIndica Studio and open it again.
  2. Check that another program is not blocking localhost.
  3. Make sure ffmpeg is installed and available on PATH.
  4. Read desktop.log in the VoxIndica app-data folder for the [sidecar] and [desktop] lines: ~/.local/share/studio.voxindica.desktop/ (Linux), ~/Library/Application Support/studio.voxindica.desktop/ (macOS), or %APPDATA%\studio.voxindica.desktop\ (Windows).
